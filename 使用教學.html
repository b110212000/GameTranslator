GAMETRANSLATOR · v0.5.0

聽原聲，看懂隊友說什麼。

從安裝、選模型，到遊戲與 Discord 接線，一次設定好。這份教學隨程式附上，沒有網路也能查看。

Windows 10／11 · 64 位元本機辨識與翻譯雙語字幕・不朗讀
1. 安裝程式2. 下載與存放模型3. 接好聲音4. 開始與字幕定位遇到問題更新、搬家與移除
STEP 01

安裝到你想放的位置

  1. 雙擊 GameTranslator-Setup-v0.5.0.exe。
  2. 選擇程式資料夾，例如 D:\Apps\GameTranslator。預設安裝在目前使用者的 AppData；選擇你有寫入權限的資料夾。
  3. 選擇是否安裝 NVIDIA GPU 加速檔案，以及是否建立桌面捷徑。GPU 檔案約 1.6 GB；沒有相容 GPU 時仍可用 CPU。
  4. 選擇模型資料夾，例如 D:\GameTranslatorModels，並選擇模型組合。
  5. 確認內容後按「開始安裝」。完成頁可開啟 App 和本教學。
程式與模型可以放在不同磁碟。安裝包包含程式與可選的 GPU 函式庫，模型在安裝後由你按下載；不會自動開始收音，也不會自動安裝音效驅動。

不需要安裝 Python。此測試發行版尚未做程式碼簽章，Windows 可能顯示未知發行者；請先核對檔案來源及附上的 SHA-256。

STEP 02

第一次開啟：下載模型

  1. 首次設定視窗會顯示安裝時選擇的模型資料夾。需要修改時按「瀏覽…」及「套用位置」。
  2. 選模型組合，按「下載建議模型」。各模型會依序下載，已完整安裝的模型會略過。
  3. 等待顯示模型已就緒，按「完成設定」。之後可從主視窗的「模型管理」重新開啟。
模型組合用途約需下載
通用（建議）中英混合／日文使用 small；純英文使用 base.en；含英→中、日→英翻譯。800 MB
純英文base.en 與英→中，較快；不能正確辨識中文。220 MB
多語高準確多語 turbo，另含 small 作自動 CPU 備用及英日翻譯。建議相容 NVIDIA GPU。2.4 GB

大小為估計，可能隨上游模型調整。建議模型磁碟預留至少 3 GB；下載與匯入暫存也使用選定的模型資料夾。

下載需要網路；完成後，語音辨識與翻譯只讀本機模型，沒有每句翻譯的 API 額度。GPU 與 CPU 的速度依電腦而異。

已經有模型，不想重新下載？

先在模型清單點選對應模型，例如「多語輕量 small」，按「匯入選取模型…」，選擇內含 model.bin 的完整模型資料夾。Argos 模型則選內含 metadata.json 與 model 子資料夾的那一層。程式會複製模型到目前選定位置，保留原檔案。

舊版 Hugging Face 模型通常位於使用者 .cache\huggingface\hub 的模型快照資料夾；匯入對話框會優先帶到已找到的舊模型位置。整個新版模型資料夾也可以直接複製到其他磁碟，再按「套用位置」。

STEP 03

把遊戲聲音送進 App，再送到耳機

翻譯遊戲或 Discord 的輸出，需要先安裝 VB-CABLE 官方虛擬音效驅動。依官方說明解壓縮，以系統管理員執行驅動安裝，再重新啟動電腦。這是另外一次驅動安裝；GameTranslator 不會代為修改系統預設音效。

遊戲／Discord→CABLE Input→CABLE Output→GameTranslator→耳機＋字幕
在哪裡設定選什麼
Discord／遊戲的聲音輸出CABLE Input（虛擬線的送入端）
GameTranslator「接收聲音」CABLE Output，優先選 Windows WASAPI
GameTranslator「耳機輸出」你的實體耳機或喇叭
Discord／遊戲的麥克風輸入你的實體麥克風，讓隊友聽見你

Discord

在 Discord「使用者設定 → 語音與視訊」把輸出裝置設成 CABLE Input，輸入裝置保持自己的麥克風。其他人的聲音會送入 App。

遊戲

若遊戲支援獨立語音輸出裝置，將語音輸出設成 CABLE Input，其他音效仍留在耳機。否則送進虛擬線的遊戲音效、音樂與語音會一起被收到，可能影響辨識。

自己對麥克風說話，不會自動成為 Discord 的輸出聲音。測試自己的聲音時，可將 App 接收裝置選成麥克風；請戴耳機避免回授。
STEP 04

開始翻譯，調整字幕位置

  1. 選好「接收聲音」、「耳機輸出」和「語音語言」。中英夾雜請選「中英混合」，日文請選「日文」。
  2. 按「開始即時音訊」。第一次要等本機模型載入與暖機，看到「模型已就緒」後再測試。
  3. 原文會先出現，中文完成後補上。耳機保留原聲，不朗讀中文。
  4. 要移動字幕，按「調整字幕位置」，拖曳藍色預覽條，再按「完成定位」或雙擊字幕。

上圖為文字示意。實際字幕為透明背景的單行描邊文字。

字幕每次內容更新後顯示三秒，接著自動隱藏；中文補上後重新計時。長句以省略號維持單行，完整內容留在主視窗最近六段歷史。定位時預覽不會自動消失；完成後恢復滑鼠穿透，位置會保存。

遊戲顯示模式請使用視窗化全螢幕／無邊框。可先用「開始預覽」確認位置；主視窗可最小化。定位目前以主螢幕為範圍，獨佔全螢幕不保證顯示。

遇到問題，先看這裡

狀況檢查方式
一直等不到語音看 App 音量條是否有動。來源輸出選 CABLE Input，App 接收選 CABLE Output；測自己說話則選麥克風。
有字幕但聽不到原聲確認 App 耳機輸出是實體耳機，且已按「開始即時音訊」。
模型顯示缺少確認模型管理顯示的位置，並下載或匯入對應模型。切換空資料夾不會自動搬走舊模型。
中文被辨識成英文改成中英混合，使用 small 或 turbo。純英文 base.en 不適合中文。
翻譯慢先等暖機完成。純英文可用 base.en；多語模式需較多上下文。模型管理可選 CPU 或自動 GPU，依電腦與遊戲負載調整。
遊戲中看不到字幕改成無邊框模式並按預覽。也可在主視窗查看完整字幕，分辨是顯示還是收音問題。
下載失敗或取消確認網路、磁碟空間與資料夾寫入權限，再按下載。辨識模型可使用下載快取接續；Argos 套件取消後需重新下載。
耳機或音效裝置換了停止翻譯，按「重新掃描裝置」，選擇新裝置後再開始。

噪音、重疊說話、口音和遊戲術語仍可能辨識或翻譯錯誤。若原文已經錯了，中文翻譯也可能跟著錯；模型不是百分之百準確。

更新、搬家與移除

更新：關閉 App，執行新版安裝精靈並選擇原本的程式資料夾。既有音訊與語言選擇會保留；模型位置以安裝精靈確認的路徑為準。

更換模型磁碟：停止翻譯及下載，把整個模型資料夾複製到新位置，再在「模型管理」套用新位置。確認可辨識後，再自行決定是否清除舊副本。

移除：從 Windows 已安裝的應用程式移除 GameTranslator，或執行程式資料夾中的 Uninstall.exe。模型與 settings.json 會保留，避免刪掉大型下載及個人設定。VB-CABLE 是獨立驅動，依其官方方式另外移除。

給朋友：傳送單一 GameTranslator-Setup-v0.5.0.exe 即可。對方使用自己的安裝位置、模型位置與音訊裝置設定。下載模型及安裝 VB-CABLE 仍須在對方電腦完成。
